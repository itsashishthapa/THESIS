# Fonts for the ESCAPE abstract

These local font files let XeLaTeX use the same font families as the supplied sample.

- Aptos, including Aptos Display Bold: https://www.microsoft.com/en-us/download/details.aspx?id=106087
- Times New Roman: Microsoft Core Fonts archive, https://downloads.sourceforge.net/corefonts/times32.exe
- The Aptos license is included as supplied. Font files retain their original embedded copyright and licensing metadata.

Compile from the `ESCAPE` directory with:

```sh
xelatex Abstract_ESCAPE37_Thapa_et_al.tex
```

Keep this fonts directory alongside the `.tex` file when moving the document.
